# Desktop Assistant Swarm

This folder contains the interactive swarm modes used by the workspace.

## Run modes

```powershell
python .\personal_ask_mode.py
python .\coding_ask_mode.py
python .\web_ask_mode.py
python .\main.py
python .\security_desk.py
```

## Personal agent

Use `personal_ask_mode.py` when you want one looped agent that can handle code work, research, OS tasks, and browser actions from the same prompt stream.

## Coding agent

Use `coding_ask_mode.py` when you want the agent to inspect the repository, debug code, suggest improvements, and write structured edits in the workspace.

## Web research mode

Use `web_ask_mode.py` for terminal-only summaries with source links, or for explicit YouTube requests.
